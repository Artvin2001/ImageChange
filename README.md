# ImageChange
Image change FLUX.2-klein-4B

Было выполнено преобразование 20 изображений при помощи промтов с использованием модели FLUX.2-klein-4B. Также был использован Google Colab, так как компьютер с ОЗУ 8Гб не подходит для использования даже облегченных и соптимизированных моделей по изменению изображений.

Итоговый датасет расположен в файле editing_result.json. В датасете содержаться следующие поля: id исходного изображения, промт, id финального изображения.

Исходные изображения находятся в папке input_images, финальные изображения находятся в папке output_images. В папке src находится код notebook в Google Colab.
